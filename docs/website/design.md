# 1. Purpose

This document defines the visual language of the Green Stag website.

Its purpose is not merely to describe colours, fonts and layouts.

Its purpose is to create a consistent visual experience that reinforces the philosophy, worldview and identity expressed within the website content.

Visitors should leave the website with the impression that Green Stag is:

- Thoughtful.
- Curious.
- Intelligent.
- Deliberate.
- Optimistic.
- Trustworthy.

The design should support those impressions.

It should never distract from them.

---

# 2. Design Philosophy

The Green Stag website should feel less like a commercial website and more like a place of exploration.

Visitors should feel as though they have entered a thoughtfully designed observatory, library or workshop rather than a sales platform.

The website should create space for reflection.

It should encourage reading.

It should reward curiosity.

The visual experience should support the content rather than compete with it.

Many websites attempt to create excitement.

Green Stag should create interest.

Many websites attempt to create urgency.

Green Stag should create understanding.

The overall feeling should be calm, confident and intentional.

---

# 3. Brand Expression

The Green Stag visual identity should communicate:

Curiosity.

Exploration.

Stewardship.

Understanding.

Perspective.

Possibility.

Long-term thinking.

The website should not communicate:

Hype.

Exclusivity.

Artificial scarcity.

Aggressive marketing.

Startup culture.

Corporate bureaucracy.

The visual language should feel timeless rather than fashionable.

The objective is to create a website that remains effective years from now rather than one that follows temporary design trends.

---

# 4. Visual Personality

If Green Stag were described as a physical place, it would feel like:

A quiet observatory.

A modern library.

A thoughtful workshop.

A place where ideas are explored rather than sold.

A place where complexity is examined rather than avoided.

The design should consistently reinforce this personality.

---

# 5. Colour Philosophy

The existing website relies heavily on purple and cyan accents.

While visually effective, this palette creates associations with cyberpunk aesthetics and technology startups.

The revised website should evolve toward a palette more aligned with Green Stag's identity.

Green should become the dominant accent colour.

The visual language should feel grounded, natural and intentional.

Technology remains present.

Nature becomes equally present.

The result should feel more balanced and distinctive.

# 20. Component Philosophy

The Green Stag website should be built from a small number of reusable components.

The purpose of components is not efficiency alone.

The purpose is consistency.

Visitors should experience a coherent visual language across every page. Every component should feel as though it belongs to the same system.

Components should prioritise:

- Clarity.
- Readability.
- Consistency.
- Simplicity.

Components should avoid:

- Excessive decoration.
- Unnecessary complexity.
- Visual novelty for its own sake.

# 41. Responsive Design Philosophy

The mobile experience is not a reduced version of the website.

The mobile experience is the website.

All design decisions should be validated against mobile layouts before desktop refinements are considered.

The reading experience, navigation experience and visual hierarchy should remain equally effective across all supported screen sizes.

A visitor reading the Philosophy page on a phone should have the same sense of clarity and calm as a visitor reading it on a desktop display.

---

# 42. Responsive Breakpoints

Mobile:

0px – 767px

Tablet:

768px – 1023px

Desktop:

1024px+

Large Desktop:

1440px+

The design should scale naturally between breakpoints.

Avoid abrupt layout changes wherever possible.

---

# 43. Mobile Layout Rules

Content should flow in a single column.

Cards should stack vertically.

Navigation should collapse into a mobile menu.

Images should resize automatically.

Videos should remain responsive.

Horizontal scrolling is not permitted.

Content should never require pinch-to-zoom.

---

# 45. Reading Experience Standards

The website contains substantial long-form content.

Reading comfort should therefore be considered a primary design objective.

The visitor should never feel rushed.

# 46. Accessibility Philosophy

Accessibility should not be treated as a compliance exercise.

Accessibility should be treated as a natural extension of the Green Stag philosophy.

If understanding is important, then content must remain accessible.

If clarity is important, then navigation must remain accessible.

If curiosity is important, then barriers to exploration should be reduced wherever practical.

---

# 47. Accessibility Requirements

Minimum Standard:

WCAG AA

---

Requirements:

Keyboard accessible navigation.

Visible focus states.

Accessible link styling.

Accessible form fields.

Sufficient colour contrast.

Responsive layouts.

Readable typography.

Logical heading structure.

---

# 48. Colour Accessibility

Accent colours must remain readable against dark backgrounds.

Text must never rely solely upon colour to communicate meaning.

Important actions should remain understandable without colour perception.

Contrast should be prioritised over aesthetics when conflicts arise.

---

# 49. Motion Philosophy

Motion should support orientation.

Motion should support clarity.

Motion should support feedback.

Motion should never exist purely for decoration.

The visitor should notice the result of motion rather than the motion itself.

---

Excessive movement.

Distracting animations.

Continuous motion.

Rotating elements.

Artificial visual spectacle.

Attention-seeking transitions.

# 73. The Experience Model

The Green Stag website should not feel like a traditional company website.

It should feel like the beginning of a journey.

Visitors should feel they are exploring ideas rather than consuming marketing.

The experience should move through three emotional states:

Curiosity

↓

Understanding

↓

Reflection

The design should support this progression throughout the site.

---

# 74. First Impression Requirements

When a visitor arrives on the Home page, the first five seconds should communicate:

This is different.

This is thoughtful.

This is worth reading.

The website should immediately distinguish itself from:

- Corporate websites.
- Technology startups.
- Consultancy firms.
- Product landing pages.

The first impression should create intrigue without creating confusion.

---

# 75. Home Page Atmosphere

The Home page should feel cinematic.

The hero video establishes mood.

The content establishes meaning.

The transition between the two should feel seamless.

Visitors should move naturally from visual atmosphere into intellectual engagement.

The Home page is the only page where the visual experience should dominate the opening moments.

Every subsequent page should prioritise reading.

---

# 76. Philosophy Page Atmosphere

The Philosophy page is the intellectual heart of the website.

It should feel almost like reading a modern essay or manifesto.

The page should encourage slower reading.

Generous whitespace should be used.

Visual interruptions should be minimal.

This page should contain the highest concentration of long-form content on the website.

---

# 77. Approach Page Atmosphere

The Approach page should feel more structured.

Readers should feel that philosophy is being translated into practical thinking.

Visual hierarchy should be stronger than on the Philosophy page.

Sections should feel distinct.

The page should communicate clarity and method without becoming overly technical.

---

# 78. About Page Atmosphere

The About page should feel personal.

Not personal in the sense of biography.

Personal in the sense of intent.

Visitors should come away understanding that Green Stag exists because of a genuine belief rather than a commercial opportunity.

Trust is the primary objective of this page.

---

# 79. Contact Page Atmosphere

The Contact page should feel welcoming.

It should not feel transactional.

It should not feel like a lead-generation form.

The page should feel like the natural conclusion of the visitor's journey through the website.

---

# 84. Reading Tempo

The website should intentionally vary reading tempo.

Fast:

Hero headlines.

Quotes.

CTAs.

---

Moderate:

Introductions.

Section summaries.

---

Slow:

Long-form content.

Philosophy.

Approach.

---

This variation creates a more engaging reading experience.

# 85. Visual Restraint

The website should practise visual restraint.

Not every section requires:

An image.

A card.

An animation.

A visual effect.

Often the most effective design choice is simply allowing content to breathe.

# 99. Decision Rule: New Components

If a worker believes a new component is required:

First ask:

Can an existing component solve this problem?

If yes:

Reuse.

If no:

Create proposal.

Do not introduce visual inconsistency.

Does this support understanding?

Does this support curiosity?

Does this support reflection?

Does this support trust?

Does this feel like Green Stag?

# 101. Failure Conditions

The implementation should be rejected if it feels:

Corporate.

Sales-focused.

Over-designed.

Trend-driven.

Startup-like.

Cryptocurrency themed.

Artificially futuristic.

Visually noisy.

# 102. Success Conditions

The implementation should be approved if visitors describe it as:

Thoughtful.

Calm.

Intelligent.

Distinctive.

Readable.

Professional.

Curious.

Memorable.

# 103. Final Design Principle

Every design decision should support the same objective.

Help visitors see more clearly.

If a decision improves understanding, it is probably correct.

If a decision obscures understanding, it is probably wrong.

This principle takes precedence over aesthetics, trends and personal preference.
